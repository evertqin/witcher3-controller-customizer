# Compatibility

Development baseline: observed 5.01 DX12, input format 60; exact required native sources and compiler are fingerprint-pinned in data/compatibility.json.
Install refuses mismatching executable, input format, hooks or shared Souls bindings before mutation.
Generated metadata derives from the owned legacy fixtures; no wholesale native script is distributed.
The local DX11 executable is absent; no DX11 acceptance claim is made.
Menu discovery worked without modifying either renderer file list.
Known legacy diagram override requires explicit reversible isolation; other overrides and compiled blobs need separate compatibility testing.
Controller Back drives automated pause entry; repeated keyboard Escape entry currently fails after riding, including with alias routing disabled.
Only normal Xbox glyphs at the current UI scale were inspected; other devices/scales remain untested.
See phase1-evidence.md and manual-acceptance.md before treating the candidate as a release.
